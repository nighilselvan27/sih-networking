2 Files

Details about the files used in this dataset.

2.1 Pcap files

  • capture20110810.pcap

    It is a capture with all the traffic (background, normal and botnet). This pcap file is not made public because it contains too much private information about the users of the network.

  • botnet-capture-20110810-neris.pcap

    Capture with only the botnet traffic. It is made public.

2.2 Netflow files

  • capture20110810.pcap.netflow.labeled

    This file has the netflows generated by a unidirectional argus. The labels were assigned as follows:

    1. First put Background to all the flows.
    2. Put LEGITIMATE to the flows that match some filters.
    3. Put Botnet to the flows that come to or from the IP address 147.32.84.165

The filters for normal (or legitimate) traffic had the IP address of our co-workers in the lab that we are sure were not infected because we check their computers by hand.
